# MedTrack — منصة دوائي

منصة ويب لتنظيم أدوية العائلة ومواعيدها الطبية، بواجهة عربية.
مشروع تخرج — الجامعة الدولية الخاصة للعلوم والتكنولوجيا.

## الفكرة
تساعد العائلة على متابعة أدوية أفرادها وجرعاتهم ومواعيدهم الطبية في مكان واحد.
المنصة أداة تنظيمية فقط، لا تقدم تشخيصاً ولا توصيات علاجية ولا تقترح جرعات أو بدائل.

## التقنيات
- الواجهة: React + Vite
- الخادم: Node.js + Express
- قاعدة البيانات: PostgreSQL

## المزايا
- ملف مستقل لكل فرد من العائلة
- تسجيل الأدوية والجرعات وأوقاتها
- جدول الجرعات اليومي مع تأكيد الأخذ
- حساب تقديري لتاريخ نفاد الدواء
- المواعيد الطبية والتحاليل
- مشاركة ملف المريض مع الطبيب عبر رابط مؤقت ورمز QR
